# Muntasir Al Mamun - Signature Animation

A gorgeous, elegant, and professional signature animation built with React and Framer Motion.

## 🎨 Features

- **Smooth 3D Animations**: Letters animate with spring physics and 3D transforms
- **Gradient Effects**: Beautiful gradient colors with purple and blue tones
- **Floating Particles**: Ambient particle effects for added elegance
- **Glowing Orbs**: Animated background glow effects
- **Responsive Design**: Works perfectly on all screen sizes
- **Professional Typography**: Clean, modern font styling

## 🚀 Technologies Used

- **React 19** - Modern UI library
- **Vite** - Lightning-fast build tool
- **Framer Motion** - Production-ready animation library
- **CSS3** - Advanced styling with gradients and transforms

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Usage

The application automatically displays the signature animation when you run the development server. The animation features:

1. **Letter-by-letter reveal** with 3D rotation effect
2. **Animated underline** that draws itself
3. **Subtitle fade-in** with smooth transition
4. **Continuous particle animation** in the background
5. **Pulsing glow orbs** for ambient effects

## 🎨 Customization

To customize the animation, edit `src/SignatureAnimation.jsx`:

- Change the name by modifying the `name` constant
- Adjust the title by modifying the `title` constant
- Customize colors in `src/SignatureAnimation.css`
- Modify animation timings in the component's variants

## 📱 Responsive

The animation is fully responsive and optimized for:
- Desktop screens (1920px+)
- Tablets (768px - 1024px)
- Mobile devices (320px - 767px)

## 🌟 Animation Details

- **Spring animations** for natural, physics-based motion
- **Stagger effect** for sequential letter animations
- **Gradient text** with background-clip for modern look
- **Shimmer effect** on the background for added depth
- **Hover interactions** on letters for playful engagement
