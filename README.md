# Muntasir Al Mamun - Interactive 3D Minecraft Portfolio

A gorgeous, interactive 3D Minecraft-style portfolio game built with React, Three.js, and Framer Motion. Experience a unique blend of professional portfolio presentation and playable game mechanics!

## 🌐 Live Demo

Visit the live site: [https://muntasir-mamun7.github.io/Gtest1.0/](https://muntasir-mamun7.github.io/Gtest1.0/)

## 🎮 Features

### 3D Minecraft World Mode
- **Advanced 3D Graphics**: Built with Three.js and React Three Fiber
- **Shader-Based Rendering**: Custom shader materials for grass and blocks
- **Shadow Mapping**: Realistic shadows cast by directional and spot lights
- **Volumetric Lighting**: Beautiful volumetric spotlight effects
- **Post-Processing Effects**: Bloom and vignette for enhanced visuals
- **Interactive Blocks**: Hover and click blocks to reveal developer information
- **Animated Particles**: 20+ floating golden particles throughout the scene
- **Treasure Chest**: Interactive chest that opens to reveal developer passion
- **Minecraft Trees**: Decorative pixel-perfect trees with leaves
- **Special Blocks**: Diamond and Redstone blocks with emissive materials
- **Starry Sky**: 5000+ stars with realistic fade and movement
- **Animated Clouds**: Moving cloud formations in the sky
- **Multiple Control Modes**:
  - **Orbit View**: Click and drag to rotate, scroll to zoom
  - **First Person**: Pointer lock controls for immersive exploration
- **Developer Info Display**:
  - Central tower showcasing name, role, location, focus, and passion
  - Skills blocks displaying programming languages
  - Technology showcase with blockchain, tools, and learning areas
  
### Signature Animation Mode
- **Smooth Pixel Animations**: Minecraft-style blocky letter animations
- **Spring Physics**: Natural, physics-based motion
- **Hover Interactions**: Interactive letters with playful engagement
- **Gradient Effects**: Beautiful gradient colors
- **Floating Particles**: Ambient particle effects
- **Glowing Elements**: Animated background glow effects
- **Responsive Design**: Works perfectly on all screen sizes

## 🚀 Technologies Used

- **React 19** - Modern UI library
- **Three.js** - 3D graphics library
- **@react-three/fiber** - React renderer for Three.js

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Usage

The application features two modes:

### 3D Game Mode (Default)
1. **Explore the world** using orbit controls (drag to rotate, scroll to zoom)
2. **Click on blocks** to reveal developer information
3. **Open the treasure chest** by clicking on it
4. **Switch to First Person mode** for an immersive experience
5. **Discover skills and technologies** displayed on interactive blocks

### Signature Animation Mode
1. Watch the **letter-by-letter reveal** with pixel-style bounce
2. See the **animated underline** build like placing blocks
3. Enjoy the **continuous particle animation** in the background
4. **Hover over letters** for playful interactions
